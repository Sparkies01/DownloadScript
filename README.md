# DownloadScript

Organized download packages for NIX HUB content.

## Structure

```text
Heroes/
Skins/
  Visual/
  Upgrade/
  Painted/
  Custom/
Effects/
  Emote/
  Recall/
  Respawn/
  Elimination/
  Notification/
  Trail/
Interface/
  LoadingIntro/
  HeroInterface/
  BackgroundUI/
  Analog/
  BGMusic/
Maps/
Tags/
Menu/
```

Use descriptive, versioned ZIP names such as
`Visual-Hayabusa-Shura-v1.zip`. Keep the original resource directories at
the ZIP root without an additional wrapper folder.
